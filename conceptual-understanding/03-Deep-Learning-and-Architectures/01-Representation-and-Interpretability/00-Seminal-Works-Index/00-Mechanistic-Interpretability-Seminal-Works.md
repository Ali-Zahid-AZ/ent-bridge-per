| **Paper**                                                          | **Summary**                                                                                                                                                                                                                                                                                                                                       | **Link**                                                                                                                | **Acquired** |
| ------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------- | ------------ |
| **Feature Visualization** (2017)                                   | This foundational work establishes how to visualize the features that individual neurons in a neural network are looking for. It introduces techniques like optimization-based visualization to move beyond simple activation maps. This paper set the visual standard for later "circuits" research.                                             | [Link](https://distill.pub/2017/feature-visualization/)                                                                 | Y            |
| **Zoom In: An Introduction to Circuits** (2020)                    | It proposes that neural networks can be understood as a collection of human-understandable "circuits" that compute specific functions. The authors reverse-engineer vision models to find curve detectors and pose-invariant features. It argues that features, not neurons, are the fundamental unit of analysis.                                | [Link](https://distill.pub/2020/circuits/zoom-in/)                                                                      | Y            |
| **A Mathematical Framework for Transformer Circuits** (2021)       | This paper provides the first rigorous mathematical description of how information flows through a Transformer's residual stream. It identifies "induction heads" as a key mechanism for in-context learning. It establishes the "circuit" metaphor for Large Language Models.                                                                    | [Link](https://www.anthropic.com/research/a-mathematical-framework-for-transformer-circuits)                            | Y            |
| **Grokking: Generalization Beyond Overfitting** (2022)             | It discovers the "grokking" phenomenon where a model suddenly transitions from memorization to perfect generalization long after training seems to have plateaued. Mechanistic analysis reveals this happens when a model finally "finds" the correct algorithmic circuit. It has become a cornerstone for understanding model training dynamics. | [Link](https://arxiv.org/abs/2201.02177)                                                                                | Y            |
| **Locating and Editing Factual Associations in GPT (ROME)** (2022) | This work introduces Causal Tracing to pinpoint where specific facts are stored in an LLM's MLP layers. It demonstrates that you can "edit" a model's knowledge by adjusting a small set of weights. It proves that factual associations are localized and directly accessible.                                                                   | [Link](https://rome.baulab.info/)                                                                                       | Y            |
| **Toy Models of Superposition** (2022)                             | It mathematically explains "superposition," where models pack more features into their latent space than they have available neurons. The paper describes why neurons are often "polysemantic" and respond to multiple unrelated things. It identifies high-dimensional geometry as the key to understanding model density.                       | [Link](https://arxiv.org/abs/2209.10652)                                                                                |              |
| **In-context Learning and Induction Heads** (2022)                 | This paper expands on the discovery of induction heads as the primary engine behind a model's ability to learn from prompts. It tracks the emergence of these heads during training and links them to sudden jumps in performance. It offers a mechanistic explanation for how models "copy and paste" patterns.                                  | [Link](https://arxiv.org/abs/2209.11895)                                                                                |              |
| **Interpretability in the Wild** (2022)                            | This is the first major study to reverse-engineer a complex linguistic task (Indirect Object Identification) in a production model (GPT-2 Small). It identifies a specific 26-head circuit responsible for the logic. It proves that mechanistic interpretability scales to real-world, "wild" models.                                            | [Link](https://arxiv.org/abs/2211.00593)                                                                                |              |
| **Towards Monosemanticity: Dictionary Learning** (2023)            | It introduces Sparse Autoencoders (SAEs) to decompose polysemantic neurons into interpretable "features." This allowed researchers to map millions of distinct concepts in models like Claude. It provides a path to overcoming the "messiness" of superposition in LLMs.                                                                         | [Link](https://www.anthropic.com/research/towards-monosemanticity-decomposing-language-models-with-dictionary-learning) |              |
| **Causal Mediation Analysis for LLMs** (2020/21)                   | These works (Vig et al.) pioneered the use of causal interventions to understand which layers and heads are responsible for specific linguistic behaviors. They established the methodology of "patching" activations to measure their causal influence. This laid the procedural groundwork for most modern circuit analysis.                    | [Link](https://arxiv.org/abs/2004.12265)                                                                                |              |
