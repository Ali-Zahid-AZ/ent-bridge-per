| **Title & Year**                     | **Core Innovation**                                                                                                                                       | **"Scratch" Implementation Note**                                                                                                                             | **Link**                                                                                                                                                         |
| ------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Attention Is All You Need** (2017) | **The Transformer**<br><br>  <br><br>Introduced Self-Attention, Multi-Head Attention (MHA), and the Encoder-Decoder stack.                                | This is your base class. Implement `scaled_dot_product_attention` and `MultiHeadAttention` exactly as described here first.                                   | [ArXiv PDF](https://www.google.com/search?q=https://arxiv.org/pdf/1706.03762.pdf)                                                                                |
| **BERT** (2018)                      | **Bidirectional Encoder**<br><br>  <br><br>Introduced Masked Language Modeling (MLM) to capture context from both left and right.                         | Focus on the **Embedding Layer**. You need to add a learnable `SegmentEmbedding` to distinguish sentence A from sentence B.                                   | [ArXiv PDF](https://www.google.com/search?q=https://arxiv.org/pdf/1810.04805.pdf)                                                                                |
| **GPT-2** (2019)                     | **Causal Decoder**<br><br>  <br><br>Proved that a decoder-only architecture with a causal mask (upper triangular matrix) is sufficient for general tasks. | Implement the **Causal Mask**. Ensure your attention matrix sets all values above the diagonal to `-inf` before Softmax.                                      | [OpenAI PDF](https://www.google.com/search?q=https://d4mucfpksywv.cloudfront.net/better-language-models/language_models_are_unsupervised_multitask_learners.pdf) |
| **RoFormer** (2021)                  | **RoPE (Rotary Embeddings)**<br><br>  <br><br>Replaced absolute positional encodings with a rotation matrix to capture relative positions.                | **Critical for LLaMA/modern LLMs.** You do not add a separate position tensor; you apply a complex rotation to $Q$ and $K$ vectors inside the attention head. | [ArXiv PDF](https://www.google.com/search?q=https://arxiv.org/pdf/2104.09864.pdf)                                                                                |
| **GLU Variants** (2020)              | **SwiGLU**<br><br>  <br><br>Replaced standard FFNs (ReLU/GELU) with Gated Linear Units.                                                                   | Change your FFN class. Instead of `Up -> Act -> Down`, do `(Up1 * SiLU(Up2)) -> Down`. Requires 3 matrix multiplications per layer, not 2.                    | [ArXiv PDF](https://www.google.com/search?q=https://arxiv.org/pdf/2002.05202.pdf)                                                                                |
| **RMSNorm** (2019)                   | **Root Mean Square Norm**<br><br>  <br><br>Simplified LayerNorm by removing mean-centering to improve stability and speed.                                | Replace `LayerNorm`. Remove the subtraction of the mean ($\mu$); only divide by the root mean square of the input.                                            | [ArXiv PDF](https://www.google.com/search?q=https://arxiv.org/pdf/1910.07467.pdf)                                                                                |
| **Switch Transformer** (2021)        | **Mixture of Experts (MoE)**<br><br>  <br><br>Decoupled parameters from compute using sparse routing.                                                     | Implement a **Router (Gate)**. Your FFN layer must now select the Top-K (usually 2) experts from a list of $N$ experts and process only those.                | [ArXiv PDF](https://www.google.com/search?q=https://arxiv.org/pdf/2101.03961.pdf)                                                                                |
| **Vision Transformer** (2020)        | **ViT**<br><br>  <br><br>Applied Transformers to images by treating 16x16 patches as "words".                                                             | Write a **Patch Embedding** layer (Conv2d with `stride=kernel_size`) to flatten images into a sequence of vectors, then feed to a standard Encoder.           | [ArXiv PDF](https://www.google.com/search?q=https://arxiv.org/pdf/2010.11929.pdf)                                                                                |
| **Swin Transformer** (2021)          | **Shifted Windows**<br><br>  <br><br>Hierarchical attention that limits scope to local windows for efficiency.                                            | Implement **Window Partitioning**. You need to reshape your tensor to group local patches, attend within them, and then "shift" the grid for the next layer.  | [ArXiv PDF](https://www.google.com/search?q=https://arxiv.org/pdf/2103.14030.pdf)                                                                                |
| **Transformer-XL** (2019)            | **Segment-Level Recurrence**<br><br>  <br><br>Allowed attention to flow across fixed-context boundaries.                                                  | Implement **State Caching**. Stop gradients (`detach()`) on the previous segment's hidden states and concatenate them to the current $K$ and $V$.             | [ArXiv PDF](https://www.google.com/search?q=https://arxiv.org/pdf/1901.02860.pdf)                                                                                |
| **FlashAttention** (2022)            | **IO-Awareness**<br><br>  <br><br>Optimized attention by tiling matrix operations to fit in GPU SRAM.                                                     | _Advanced._ This is a systems optimization. Study this to understand how to write a custom CUDA kernel that fuses the Attention operation.                    | [ArXiv PDF](https://www.google.com/search?q=https://arxiv.org/pdf/2205.14135.pdf)                                                                                |
| **Formal Algorithms** (2022)         | **Mathematical Spec**<br><br>A DeepMind paper defining Transformers purely in pseudocode/math, no frameworks.                                             | **The Bible for scratch builders.** Use this to verify your Python implementation against a pure mathematical standard.                                       | [ArXiv PDF](https://www.google.com/search?q=https://arxiv.org/pdf/2207.09238.pdf)                                                                                |
